# ADR-0039 — Artifact materialization ownership and exclusive Linux commit

Date: 2026-10-11. Task: CMP-08. Decision implemented; behavior **DEFERRED / NOT VERIFIED**.

CMP-07 is bound manifest metadata and does not contain bytes. Compiler-neutral rules forbid persistence capabilities. Existing Django/DRF HTTP adapters and approved final byte producers are absent. Materialization must preserve original compilation status, complete manifest membership and exactly defined producer bytes, while keeping publication/runtime authority outside this task.

Keep pure writer contracts/preflight/immutable plan/result/receipt in compiler-core. Declare a separate tooling-owned artifact-writer module with constrained artifact-materialization profile and only compiler-core public API dependency. All file operations reside in that module's Linux infrastructure adapter; compiler-core never imports the adapter. Do not relax neutral-zone stdlib restrictions or create exceptions. Approved server root configuration is adapter-owned. Future HTTP wiring requires established authorization, no endpoint now.

Use explicit CMP-07 concrete frozen kind approval plus a named immutable bytes field (and optional declared SHA-256 field), not generic serialization or encoding. Sources reference supplied original compiler artifact objects exactly once; original output_origin and full manifest descriptors/outcomes/input/configuration are rechecked. No producer is invented to make Mini Sales runnable. In-process trusted associations are not portable authenticated provenance.

Use validated flat portable lowercase filenames and complete explicit layout or deterministic kind__key.bin. Reject all unknown bytes/kinds, missing/extra sources, path ambiguity and collisions before filesystem mutation. Destination is a logical server root reference plus output-set token. Only existing explicitly approved Linux local roots with controlled ownership/ancestry are allowed; walk all components using no-follow directory handles.

Use writer-owned same-root 0700 private staging, exclusive 0600 regular files, exact readback/length/inode/inventory verification and optional declared byte-digest verification. Track exclusive-open inodes before writing and clean only those owned resources. Preserve original failure and separate cleanup failure; no recursive unknown cleanup.

Commit once through Linux renameat2 RENAME_NOREPLACE. FAIL_IF_EXISTS is the only supported write policy, including repeated requests and cross-process races. No unsafe replacement fallback. Platform/mount failure fails closed. Atomic visibility, synchronization and cross-process exclusivity are distinct. Visible mode claims complete visibility; synchronized mode fsyncs files/stage/parent. Post-rename sync failure retains committed_destination without success receipt; committed output is never deleted as rollback. Privileged/same-UID attackers, administrator root moves, remote mounts, universal power-loss durability and crash cleanup are outside v0 guarantees.

Use existing compiler statuses/diagnostic family with CMP-044..061, typed write-stage/relative-location associations and full receipt metadata, no payload retention. Receipt facts do not publish/authorize/activate/deploy/execute. Preserve existing tests and prior archives; latest CMP-08 section 37 explicitly requires **one archive Markdown document without README**, overriding generic older archive layout only for CMP-08. [158 cases](../../../test-archive/CMP-08/CMP-08-deferred-tests.md), all NOT_RUN — DEFERRED. Do not implement CMP-09.
