## Value semantics and constraints

Unknown FieldId rejects; it is never discarded or mapped to Missing. Values must be exact approved canonical variants and deeply immutable before they enter trusted authorization. Absent known fields request the canonical Missing, never Null/zero/False/empty string/default. Adapter returning another variant for missing input rejects RUN-219.

Required checks presence; Nullability checks explicit Null independently. Required+Nullable allows Null but forbids Missing. Optional+NonNullable allows Missing but forbids Null. Removal is an explicit canonical Missing assignment; no None ambiguity and no whole-instance deletion.

Supported Value projections are exact Python str/bool/int/Decimal/date/datetime/UUID. Boolean is not Integer; DateTime is not Date; UUID/date strings and floats are not parsed/coerced. Datetime supports no timezone or immutable standard datetime.timezone; no timezone conversion/awareness policy is inferred.

## Immutable operations, reads and revisions

Create validates complete membership/values/constraints before invoking canonical construction, then rechecks canonical instance immutability, original identity, exact version/context and identical ordered normalized values. Success returns a complete metadata wrapper and the real canonical instance, revision 0. Failure/incomplete contains no partial state.

Update requires the same exact original definition entry, context/target and canonical approval as the original state. It revalidates original state, verifies expected revision, rejects duplicate/unknown changes, preserves unchanged fields, validates the complete candidate, calls canonical construction and checks a new canonical object was returned. InstanceId and semantic version remain unchanged. Explicit no-op/empty changes still produce a new canonical object and revision+1. Any rejection returns no new state; the service never mutates the original.

RuntimeInstanceRevision is a nonnegative local integer; default ceiling 2^63−1. Update at ceiling rejects rather than wraps. A mismatch rejects RUN-218. Same supplied state/changes/identity/definition/policy yield equivalent outputs under the approved deterministic adapters. Revisions provide local lineage only: two callers can independently transform the same old state into two revision+1 values. No shared-store CAS, persistent uniqueness, cross-process coordination or distributed concurrency guarantee exists. No existing TYPE-08 revision contract is overwritten; once that real contract exists it must be reconciled with this wrapper.

Inspect requires its own authority and normal RUN-02 exact lookup. It rechecks the canonical state/schema/constraints, and returns all fields in declared order or only the explicit selected FieldId. Known Missing returns MISSING with canonical Missing, known Null/Value returns FOUND; unknown field INVALID_FIELD/RUN-210. Invalid context INVALID_CONTEXT. Rejected reads expose no values. Inspect performs no construction/update, database query or relationship load.
